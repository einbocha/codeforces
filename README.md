# CODEFORCES

This project includes my solutions to the exercises, written in rust (v1.89.0).


# Rust

```text
codeforces/
├── Cargo.toml
└── src/
    └── bin/               # 'cargo run --bin <name>'
        ├── 702C.rs 
        └── exercise.rs
```

# Setup

1. check the prerequisites
2. `pixi install` to get the correct rust version
3. `pixi shell` to enter the environment
4. now `cargo --version` should show `v1.89.0`
5. you can now run any rust entry point
6. e.g. `cargo run codeforces` to run `main.rs`
7. or `cargo run --bin 702C` to run another binary

## Prerequisites
- pixi
